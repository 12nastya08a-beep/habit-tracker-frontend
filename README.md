# Habit Tracker Frontend

Фронтенд-клієнт у папці `frontend/` для взаємодії з бекендом Django REST Framework через CORS.

## Сторінки проєкту
1. **Реєстрація (`register.html`)** — створення нового облікового запису користувача.
2. **Логін (`login.html`)** — вхід у систему за допомогою логіна та пароля (JWT авторизація).
3. **Головна/Публічна сторінка (`index.html`)** — інформаційний контент, доступний неавторизованим користувачам.
4. **Мої звички (`dashboard.html`)** — захищена сторінка з приватним функціоналом (перегляд, створення та видалення власних звичок), доступна лише авторизованим користувачам.
5. **Вихід (`logout`)** — можливість завершити сеанс та очистити дані авторизації.

## Поведінка системи
* Неавторизованого користувача при спробі відкрити сторінку «Мої звички» автоматично перенаправляє на сторінку логіну зі збереженням попереднього маршруту.
* Після успішного входу користувача повертає на сторінку, з якої його було перенаправлено.
* Авторизований користувач не може відкрити сторінку логіну чи реєстрації — система автоматично спрямовує його на дашборд.
* У шапці сайту динамічно змінюються елементи: гість бачить кнопку «Увійти», а авторизований користувач — своє ім'я та кнопку «Вийти».
* При закінченні терміну дії `access` токена фронтенд автоматично оновлює його за допомогою `refresh` токена без примусового повторного логіну.

## Адреси та порти
* **Бекенд (Django):** `http://127.0.0.1:8000/`
* **Фронтенд:** відкривається через `frontend/index.html`(або за допомогою локального сервера розробки PyCharm).

## Як запустити проєкт
1. Переконайтеся, що бекенд запущені на порті `8000` (виконайте `python manage.py runserver` у корені бекенд-проєкту)
2. Відкрийте файл `frontend/index.html` у будь-якому веббраузері (наприклад, клацнувши правою кнопкою миші в PyCharm та обравши 'Open in Browser')
3. Зареєструйте нового користувача або увійдіть у систему для тестування захищеного функціоналу звичок.
