# Habit Tracker Frontend

Простий фронтенд-клієнт у папці `frontend/` для демонстрації взаємодії з бекендом Django REST Framework через CORS.

## Адреси та порти
- **Бекенд (Django):** `http://127.0.0.1:8000/`
- **Фронтенд:** `frontend/index.html`

## Як запустити проєкт
1. Переконайтеся, що бекенд запущено на порті `8000`.
2. Відкрийте файл `frontend/index.html` у будь-якому веб-браузері.
3. Натисніть кнопку «Завантажити список звичок».
